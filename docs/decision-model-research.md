## Engineering decisions

Five concepts stay separate: player football quality, weekly start usefulness, acquisition usefulness, this roster's marginal value, and externally observed market value. Market value remains null. K/DST do not use the skill-position acquisition model.

Replacement will prefer the actual available pool, with visible league-size/slot/scoring demand context. Add/drop simulation will retain opportunity cost, preserve IR/taxi compartments, protect structurally important/uncertain assets and disclose any platform restrictions that cannot be verified. Immediate-upgrade thresholds will be conservative configuration until historical league-level evidence can calibrate them.

Backtests will build features strictly from earlier weeks, tune on validation seasons and evaluate later held-out seasons. Current availability, current ownership, current Sleeper search ranks and future outcomes must not construct historical features. Exact historical league waiver pools are unavailable: acquisition tests evaluate underlying ranking usefulness, not realized fantasy-manager transaction performance.

## Free data and temporal provenance

[ffopportunity's public README](https://github.com/ffverse/ffopportunity/blob/main/README.md) documents training on 2006–2020 and a CC BY-SA 4.0 license for model/data outputs. Use the versioned `v1.0.0-data` release for 2022+ evaluation, record source hashes and retain attribution. The versioned model release was published in January 2022; its archive was re-uploaded in 2025, so a release label alone is not an immutable historical receipt. Results are retrospective event-time backtests on corrected public records, not a claim to reproduce exact historical publication latency. Preserve that limitation.

[nflfastR field documentation](https://nflfastr.com/articles/field_descriptions) defines yardline distance, pass/rush indicators, player IDs and no-play flags. Reproducible red-zone counts may use these fields; end-zone target locations must remain unsupported if actual intended catch location cannot be established reliably. Only allowlisted football fields enter the normalized layer; betting lines/probabilities in wide source files are discarded.

Prior-season information will be discounted for new teams/roles and absent for rookies. A sample-weighted blend is transparent shrinkage, not a claim to have fitted an empirical-Bayes population model. Historical quantiles are descriptive outcomes, not calibrated prediction intervals.

See the release model specification and reproducible backtest report for final formulas, selected parameters, results and deferred items. No provider's published performance is used as a substitute for our validation.
